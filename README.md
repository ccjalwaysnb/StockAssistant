# 股票小助手

一个使用 **C# + WPF** 开发的桌面行情工具，用于查看 A 股 / ETF 的实时行情、五档盘口、历史日 K 收盘价和当日分钟级价格数据。

这是一个个人自学与实践项目，目前主要用于实际查看 ETF 行情。

> 当前版本：**v0.9 先导测试版**

本版本的主要目标是验证行情数据获取、解析、运行时数据管理以及周期更新这一整条核心数据链路。

## 当前功能

| 功能    | 说明                                    |
| ----- | ------------------------------------- |
| 市场选择  | 支持选择沪市、深市、美股，并根据市场自动生成对应接口代码          |
| 快速搜索  | 输入纯数字股票代码，例如 `159248`，程序自动添加接口所需的市场前缀 |
| 搜索冷却  | 两次搜索之间限制 5 秒，按钮显示剩余倒计时，避免重复点击         |
| 实时行情  | 显示现价、涨跌额、涨跌幅、今开、昨收、最高、最低、成交量、成交额、换手率等 |
| 五档盘口  | 显示买一～买五、卖一～卖五                         |
| 历史日 K | 获取股票可用的历史每日行情，目前主要使用收盘价               |
| 当日分时  | 获取当日分钟级价格数据                           |
| 数据时间  | 记录并显示接口返回的数据更新时间                      |
| 周期更新  | 实时盘口与当日分时分别使用独立的更新机制                  |

## 设计思路

### 1. 启动自检流程

这是本项目第一次比较完整地实践"程序启动前置条件检查"的思路。

程序启动后并不会立即进入正式界面，而是先经过一套简单的启动流程：

```text
程序启动
    ↓
Loading
    ↓
检查 UserCache
    ↓
读取缓存
    ↓
检查是否成功
    ↓
成功 → 创建正式 UI
失败 → 停止后续流程并报告错误
```

这样做的目的不是让启动流程变得复杂，而是把"程序运行所需要的前置条件"集中处理。

后续随着缓存、自选股等功能增加，可以继续在这套启动逻辑中扩展新的检查项目。

### 2. 双心跳更新机制

项目目前采用了一个称为"双心跳"的更新设计，将不同数据源、不同更新频率的数据分开处理。

**腾讯实时行情**

```text
每 0.5 秒检查一次腾讯数据时间
        ↓
数据时间发生变化
        ↓
获取最新实时行情与五档盘口
        ↓
刷新界面

数据时间没有变化
        ↓
跳过本次更新
```

**东方财富当日分时**

```text
每 1 秒检查一次东方财富数据时间
        ↓
分钟数据发生变化
        ↓
获取最新当日分时数据
        ↓
刷新界面

数据时间没有变化
        ↓
跳过本次更新
```

这里的计时器主要用于检查数据是否发生更新，而不是无条件地反复刷新界面。

这样可以让程序根据接口实际返回的数据时间判断是否需要进一步获取和处理数据。

### 3. 根据数据频率采用不同更新策略

项目目前将数据按照更新频率进行区分，而不是让所有数据使用同一种刷新机制。

- **实时盘口**：需要尽可能及时，因此使用高频检查。
- **当日分钟数据**：本身以分钟为粒度，因此采用低频检查，只在发现新的分钟数据后更新。
- **历史日 K**：属于低频数据，目前只在用户搜索股票时获取一次，不参与实时心跳。

整体数据流可以概括为：

```text
用户搜索
 ├─→ 腾讯实时行情
 ├─→ 东方财富历史日 K
 └─→ 东方财富当日分时

程序运行期间
 ├─→ 腾讯实时行情：周期检查
 └─→ 东方财富当日分时：周期检查

历史日 K：暂不自动更新
```

### 4. 获取、处理与展示分开

代码按照功能划分为不同区域和方法，使单个方法尽量只负责一类工作。

例如腾讯行情的基本流程：

```text
TenGet()
 ├─→ 获取数据
 └─→ 刷新界面
```

实际 HTTP 请求、数据解析和 UI 刷新由不同的方法承担。

这种组织方式主要服务于代码的可读性、调试和后续扩展。

## 数据来源

本项目使用第三方公开行情接口获取数据，不提供数据服务本身。

| 数据          | 数据来源               | 用途              |
| ----------- | ------------------ | --------------- |
| 实时行情 / 五档盘口 | 腾讯财经行情接口           | 实时价格与盘口         |
| 历史日 K       | 东方财富接口             | 历史每日行情          |
| 当日分时        | 东方财富接口             | 当日分钟级价格         |
| 数据更新时间      | 腾讯 / 东方财富接口返回的时间字段 | 判断数据是否更新、显示数据时间 |

## 市场代码转换

| 市场 | 腾讯接口前缀 | 东方财富 secid         |
| -- | ------ | ------------------ |
| 沪市 | sh     | 1.                 |
| 深市 | sz     | 0.                 |
| 美股 | us     | 105.（当前暂按纳斯达克场景处理） |

## 开发思路

这个项目并不是一次性完成所有功能，而是按照以下方式逐步开发：

```text
明确需求
  ↓
设计整体流程
  ↓
确定数据来源
  ↓
设计数据流
  ↓
实现核心功能
  ↓
测试实际数据
  ↓
发现问题并调整
  ↓
逐步扩展功能
```

## 运行方式

### 环境要求

- .NET 10 SDK
- Visual Studio 2022 或更高版本（支持当前项目所使用的 .NET / WPF 环境）

### Visual Studio

使用 Visual Studio 打开：

```text
炒股小助手.slnx
```

然后直接运行项目。

### 命令行

```bash
dotnet run --project 炒股小助手/炒股小助手.csproj
```

### 使用方法

1. 启动程序，等待启动检查完成。
2. 点击"市场"按钮选择沪市、深市或美股。
3. 输入纯数字股票代码，例如 159248。
4. 点击"搜索"。
5. 查看实时行情、五档盘口、历史日 K 和当日分时数据。
6. 实时行情和当日分时数据会在运行过程中自动检查更新。
